# Primeira aula de Angular

Gerenciador de tarefas acadêmicas feito com Angular, Signals, computed, @for, @if e @empty.

## Como executar

Requisitos: Node.js 22.22.3 ou superior e npm.

```bash
npm install
npm start
```

A aplicação abre em http://localhost:4200.

## Build de produção

```bash
npm run build
```
