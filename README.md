## Projeto Integrador Angular

Gerenciador de tarefas desenvolvido em Angular.

### Funcionalidades

- Cadastro de tarefas pelo botão ou com a tecla Enter
- Bloqueio de tarefas com menos de 3 caracteres
- Concluir e reabrir tarefas
- Excluir uma tarefa, limpar as concluídas ou apagar todas
- Contadores de total, pendentes e concluídas
- Mensagem quando a lista está vazia e quando todas foram concluídas
- Layout responsivo

### Tecnologias

- Angular 22
- TypeScript
- Signals e computed
- Controle de fluxo com @for, @if e @empty
- CSS

### Como executar

É preciso ter o Node.js 22.22.3 ou superior instalado.

```bash
cd projeto
npm install
npm start
```

A aplicação abre em http://localhost:4200.
